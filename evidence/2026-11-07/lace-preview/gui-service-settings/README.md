# Signed Lace service-setting controls

The [7 November source review](source-review.json) reverified official signed Lace 2.5.1 and its `MidnightSettingsSheet` source. The node and indexer choices are disabled, display the configured addresses as text, and have no-op change handlers. Saving changes only the proof-server setting. This screen therefore offers no normal GUI node/indexer URL override.

This is source inspection, not a fresh browser action or a claim about future Lace versions. No wallet was opened, service setting changed, funding requested or transaction submitted. Internal configuration reducers do not establish a supported user-facing override. The report retains only signed-source hashes, fixed control properties and scope flags, without service query values or bundled tokens.

[Provenance](provenance.json) and [file digests](SHA256SUMS.json) bind the unchanged public report.
