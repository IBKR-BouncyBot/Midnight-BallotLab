READ THE BOUNDARIES

A prototype you can inspect.

Local cryptography. Ballots use randomized encryption, validity proofs and threshold decryption. This browser holds every demo voter credential and trustee share, so it does not provide separation between real participants.

Midnight integration is unfinished. A separate native Compact implementation is included for encrypted ballots, trustee decryption and final tally checks. The native implementation has separate compiler, runtime and browser evidence. The interactive legacy demo below uses its separate JavaScript protocol and is not Midnight-native.

Not suitable for a real election. This is unaudited research code. Synthetic credential enrollment does not establish one eligible person per credential. It does not provide coercion resistance or a secure voting device.

Nothing is saved automatically. Credentials and trustee shares stay in this tab’s memory. Refreshing closes the experiment. Export the public record and your receipts if you want to verify them later.
