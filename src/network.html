01 / CONNECT

Wallet connection

Connect to the public testnet.

Preview is a shared test network. You do not need to run your own node or indexer.

  1. Install Lace ↗ (opens in a new tab), enable Midnight and choose Preview.
  2. Get free test NIGHT from the Preview faucet ↗ (opens in a new tab), then use Generate tDUST in Lace and wait for usable DUST.
  3. Run Midnight proof server 8.1.3 using the local prover setup guide ↗ (opens in a new tab) and set Lace’s prover address to http://localhost:6300.

Use test tokens only. The local prover processes private data; public network services do not replace it.

How to set up Lace
  1. Select Midnight Preview. Open Lace and choose Settings → Network → Testnet, select Preview under Midnight, then confirm. Cardano has its own network setting.
  2. Set the local prover. In Settings → Midnight → Custom proof server, use http://localhost:6300, then choose Save configuration → Confirm and save. Keep the local proof server running when making transactions.
  3. Get free test NIGHT. Open your Midnight account in Lace, choose Receive → Unshielded, and copy the address starting with mn_addr_preview. Use it at the Preview faucet linked above, complete the CAPTCHA and request tokens. Wait for the test NIGHT balance to appear in Lace.
  4. Generate tDUST. Return to your Midnight account and choose Generate tDUST. Lace fills in your DUST address. Choose Review transaction, then Confirm to register your test NIGHT for DUST generation.
  5. Wait for usable DUST. Registration starts tDUST accruing. Wait for a usable DUST balance before creating an election or submitting a vote. Receiving test NIGHT alone does not start DUST generation.
  6. Connect to Ballot Lab. Open this app in the same browser as Lace, reload the page and choose Refresh wallet list. Select Lace, enter a separate password for this app and click Connect selected wallet.

If Midnight is missing from Lace, follow the Lace setup steps ↗ (opens in a new tab).

Use Preview test tokens only. You can check the public services without a wallet or prover, and connect Lace before funding it. Connecting does not submit a transaction.

Requires a Midnight-enabled wallet with DApp Connector API 4. Lace 2.5.0 completed an election in a local browser test. Other API-4 wallets have not been tested; Cardano-only wallets are unsupported. The full election was verified on a local development network. Public-testnet transaction validation is separate; see the guide for its current status. 02 / SET UP ELECTION

Test election

Set up or join an election.

Create a new test election with your own choices and voting schedule.

Get the contract address and fingerprint from a source you trust. The app checks that the contract’s keys and settings match, but cannot prove that its initial setup or history was honest.

Generate a new key, paste an existing key or load a saved key file.

Only the election administrator needs this key. Keep the same key to register voters. Downloaded key files are private, unencrypted text; they are never included in public receipts or election records.

Use the administrator key above for this election. After creating the contract, register the trustee keys below before leaving this page.

This test setup creates all three key shares in one place. They are not held by independent people. Two people with these shares could also decrypt individual ballots outside the app.

Register each voter before voting opens, using the administrator key. Download the voter key and load that same file when voting. 04 / REVEAL RESULTS

2 of 3

Reveal the combined results.

Voting can close only after the time set in the contract. Then two trustees each use their secret share to help reveal the total. Each contribution is checked against all accepted votes.

For automatic closing in a local test, run the timed-election operator (opens in a new tab). It needs a running node, indexer, prover, test wallet and two trustee shares. This website does not run that background service.

1. Choose a trustee

Select a trustee, then enter that trustee’s secret key share below.

2. Choose two trustees who have contributed

Both trustees must have submitted their contributions before you can reveal the results.
